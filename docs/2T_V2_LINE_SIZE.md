# ライン人数と1着側のライン先頭得点の比較

7車の研究候補。2着の同ライン版を基準とし、同ライン候補に限って「勝者候補のライン人数−2」との交互作用を加えた。ソフトマックスは同ライン候補の人数をすでに反映するので、ここで学習するのは人数によって選手一人当たりの評価をさらに変える効果。別案では、追走選手の1着側に自ライン先頭の相対競走得点を加えた。双方の係数は学習期間の結果で推定。

二車単Log Lossは小さいほど良い。どちらの追加も改善は期間横断で安定しなかった。同ライン版を継続候補とする。外部の日別配信には7月分の掲載記録が検索に残るが、2026-07-20の公開本体は404、現行履歴・タグからも発走前の版を確認できなかった。この資料から学習・精度評価レースを追加していない。
