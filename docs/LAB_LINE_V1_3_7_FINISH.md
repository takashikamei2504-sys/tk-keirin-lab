# LAB LINE V1.3.7 — 過去統計と因果展開に基づく決着再設計

## 診断の根拠（2026-11-04時点）
- 公開集計では、7車と9車で逃げ・捲り・差しの割合が異なる。特に9車は逃げが相対的に少ない。統計の「差し」は本線番手差しと同義ではない。
- 公開集計出典：競輪の決まり手に関する2021年6月〜2026年9月の集計。7車（117,205R）：逃げ25.1％／捲り29.7％／差し45.2％、9車（11,612R）：逃げ12.9％／捲り34.8％／差し52.4％。S1の逃げ12.9％／捲り30.8％／差し56.3％は別の母集団である。**S級・7車/9車の交差集計ではない**。
- 凍結済みLINE予想の評価（data/line_evaluation.json）：97レース照合、22レース的中。モデル別59R/34R/4Rで、版の異なる性能を合算して「新版の成績」としない。実際の位置取り検証はまだ観測ゼロ。
- 97Rの不的中75件中、1着候補漏れ57件、1・2着組み合わせ漏れ10件、3着候補漏れ8件。第一に1着候補と決着筋のカバレッジを改善する。着順では実際の先行ライン／番手／別線の攻防を識別できない。

## 再設計
1. 最終3〜4角で実在する外並走・接近と、先行/番手の残り脚・牽制負荷を別々に計算する。ラインの先頭と番手の能力差を競走得点や推測的な定性ラベルだけで決めない。
2. 先行押し切り・番手差し・別線捲り切り・本線番手＋別線自力・先行＋別線自力の*1・2着順序付き*仮説を競争させる。別線自力は4角の外進行があり、射程に届いている場合にのみ認める。
3. 「本線5点／同展開5点／別展開2点」は撤廃する。成立済み候補の比較評価と、同じ1・2着の買い目追加による限界カバレッジ低下を考慮して、上限12点の中から選ぶ。別筋を一定数強制採用しない。
4. 係数・比較差は依然として暫定スコア。公開統計の割合を各レースの予測確率として固定配分しない。発走前以外の成績は特徴量に混入しない。

## 反証・評価
- 各版の発走前に固定した予想は変更しない。別版の再計算結果を「当時の予想」にすり替えない。
- 7/9車別、ライン長（4-3-2-単騎）、S級の級班別に本線1着・1/2着ペア・3着カバレッジを監視。開催日、開催場、同じ対象レースで新版と旧版を比較する。
- 将来の発走前固定予想のサンプルを増やして、1着候補漏れ率と1/2着組合せ漏れ率の低下を確認する。初期の比率合わせ、後付けの改善率宣言は禁止。
