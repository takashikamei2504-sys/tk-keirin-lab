# B-AXIS v0.4｜選手個別力量・3番手追走とBライン決着の検証（2026-11-08）

## 結論
- B通過者のみを固定し、勝ち筋・上位3着はBラインにも別ラインにも許容する。
- **古性優作が寺崎浩平の直後にいる際、3番手を理由に機械的に追走離れさせる処理を修正。**
- 先行からの番手発進時にはライン元3番手がB新先頭の番手へ続く `8-3-5 → 3-5-8`（デフォルト分岐）。発進前の最終ホームでは `8-3-5` を維持する。
- 直前の車輪への追走と、B先頭からの累積距離を別項目にする。B先頭から遠いことを「自分の前の選手から千切れた」と混同しない。
- 新モデルが未検証の将来回収率を達成したと主張せず、v0.2をiPhoneの初期選択で保持。

## 実装方針と安全弁
1. `js/b-axis/follow.js`：直前の車輪との相対得点差、瞬発、近況等で追走を評価。後位の個人結果を弱く補正、千切れの実測率と混同しない。
2. `js/b-axis/phases.js`：ホームまで元ライン順序を維持し、Bで番手発進した場合は後続が追走する独立分岐を生成。B先頭からの総距離・直前車輪への追走を分離。
3. `js/b-axis/engine.js`：未見の将来日付に限って過去の選手別後位入着記録を参照。過去検証へ未来の結果を投入しない。
4. `js/b-axis/phases-v02.js` と `engine-v02.js`：比較対象の旧版は両方を凍結し、コード変更によるベースライン汚染を防ぐ。
5. iPhone画面：v0.2を初期選択にして、v0.4のB・戦法変更、6局面、後続の追走相手と相対車間を比較可能にする。上限5点の初期値は維持。
6. 1年前の個別データがなくても、WINTICKETの年別成績は参考可能。古性は2025年69走の3着以内49回、2026年66走49回、寺崎は2025年64走41回、2026年54走31回。ただし出走のグレード・ポジションが違うので直接の追走成功率とは呼ばない。
