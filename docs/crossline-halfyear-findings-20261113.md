# ラインをまたぐ決着の半年間・事後予想検証結果（2026-11-13）

## 結論
- **半年相当の実レース8,736Rをレース単位で再予想・照合したが、全レースを無条件購入して黒字となる方式は見つからなかった。**
- 本検証の最終評価期間2,359Rで、再構成した比較用8点のROI63.0%に対し、別線2ペア×3着2人の4点は87.2%、8点ハイブリッドは74.5%。見込み改善はあるが、いずれも損失。
- 高万車リスク上位570Rの4点方式119.2%（最高払戻1R除外103.9%、上位3R除外90.4%）。**高リスク7車522R**なら127.6%（最高1R除外110.7%）、**9車48R**では27.9%。この差は過去のデータ内の条件選択結果で、将来勝てる証明ではない。
- **S級7車の別線4点方式58.4%**（最終495R）。S7に一律適用するのは不適切。
- 別線1・2着ペアの選定、および三つ目のラインの3着選定が改善点。

## 的中できない原因の詳細
- 最終評価2,359Rで実際の1・2着が別ライン：**1,002R（42.5%）**。
- その正しい順序付き1・2着ペアを、予測した上位2組が含んだ：**277R**。別線決着でのペア捕捉率**27.6%**。
- さらに3着上位2人まで合って4点型が的中：**158R**。正しいペアを含んだ277Rに対する3着捕捉率**57.0%**。
- 別線決着1,002Rの3着が第3ラインの選手だった：**337R（33.6%）**。この種類の決着では4点方式の的中が**8/337R**にとどまる。別線万車券限定の旧研究では第三ライン3着43.1%と高かった。
- 4点方式はペア選定失敗（277/1,002）と第三ライン3着漏れ（8/337）が主要な改善対象。今後は展開・Bライン・追走切れ・別線番手差しの成立検証を導入する。ただし選手移動やブロックの実際の過程は着順だけで確定しない。

## 実務判断
1. 既存本番エンジン／8点購入は変更しない。研究用PR #58 はドラフトのまま保持。
2. 条件として最も試験価値があるのはA級／チャレンジ7車×万車リスク高の別線4点。**ただし上位3払戻除外では100%未満**。
3. S級7車・S級9車へ4点方式を無条件移植しない。
4. 1・2着ペアはB、先行型/番手、EX追走適性、差し・ブロック成立条件で強化。3着はラインをまたぐ第三ライン候補の割合を条件付きで校正する。選ぶのは「候補数」より「成立条件」。
5. 最低30日・200R以上の**発走前固定**で、同額8点比較と4点方式、払戻トップ1/3/5件除外、級班別・日別の回収率を別途検証。実オッズ・確率校正前のEV判定は行わない。
