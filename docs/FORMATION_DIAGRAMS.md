# 6局面の展開モデル図

`v14.html` の本線と4つの別展開に、局面名 → モデル図 → 本文 → 判断材料の順で表示する。従来の数字だけの隊列行を置き換える。予想の選定、比較係数、買い目の選択は変更しない。

## 状態と表示の契約

`story-brain.js` は各 `scene` に `tactical`（`tk-keirin-scene-state/v1`）を追加する。これは、その局面を生成した直後の状態のコピー。先頭、S取り、仕掛け、番手、外の選手、追走の接続、ブロック、内の選択等を持つ。最終場面はゴールの上位3車と4角の隊列も保存する。別展開の最終場面は、その1点の買い目に対応する上位3車を保存する。

`formation-diagram.js` の `project(scene, race, previous)` は読み取り専用。次の局面の情報や展開全体の最終フィールドを、前の局面へ流用しない。本文を解析して新たな動きも作らない。状態が付いていない旧記録では、順番だけの図とし横位置を推定しない。

- 主隊列は `scene.order` と完全一致。左を先頭、右を後方として全車を一列に配置する。車番は車色の小さな楕円で表し、選手名は直下の対応表に併記する。外・内は明示状態のある車だけ段を変える。
- 同じ英字と線色は出走表の元のライン。車番・選手名も併記し、色だけには依存しない。姓の区切りが確認できないときは、氏名を2文字で切らずフルネームを使う。
- 外は `tactical.outside`、内はエンジンが選んだ `innerRider` と `openInside` から表示。マスの幅や段差は車間・速度・実測の走路ではない。
- 赤板は「攻防」の小図と「この局面後の並び」を分ける。上昇中の動きと、その攻防の結果の隊列を混同しない。
- 接続が切れた選手は破線と追走離れラベルで表示。次の局面で、説明なしに接続が復元された状態は拒否する。
- ブロック成功時は、攻撃選手が4角直前より前進していないことを検査。ブロック方向は外への応答、縦踏みは前への動きとして矢印と文言を添える。
- ゴール図は上位3車のみを着順として表示する。残りの配列を4着以降と断定しない。4角との前後関係が逆転した選手を「交わす」と表示する。進路を新たに決めない。

追走離れがあるのにホーム図・本文で「一本棒」としていた表示の不整合は、同じ `gap` 状態に合わせて「隊列に切れ目」に揃える。選択処理への影響はない。

## 検証

`npm test` に7車・9車・2026年11月2日防府12Rの投影検証を含める。全局面の隊列、別展開の買い目との着順一致、予想データの不変性、状態のない横位置の禁止を検査する。

`tests/formation-browser.cjs` は320px・390pxで、一本棒、踏み合い、外並走、追走離れ、番手はまり、ブロック、中割り、縦踏み、着順変化を表示確認する。専用の架空状態は `tests/formation-fixtures.cjs` に隔離し、実際の予想に使わない。

`tests/mobile-preview.html` は390pxのiframeで実際のLABを開く表示確認用ページ。通常のアプリの入口やレース操作は変更しない。
