# B-AXIS 競輪常識レビュー（2026-11-07）

## 目的と対象
2026-11-01に保存された発走前入力の男子7車6レースと、2026-10-31防府12Rの9車保存サンプル（計7例）を用い、最終Bを1選手に指定した条件でB-AXISに全選手の決着予想を生成させた。各レースの結果は**予測生成入力に入れず**、ユーザー向けの戦術的な不自然さの分析にのみ参照。

本レビューは**発走前に買った予想のバックテストではない**。当時のB通過選手は未付与であり、モデルを過去の保存材料で後から走らせた開発診断である。競走得点・近況など入力がどの時点で取得されていたかは元の保存履歴に準じる。

## 修正前（v0.1）の目立った問題
1. 順位生成がB先頭のままの得点加算に強く依存。宇都宮4R、久留米6R、防府12Rサンプルを含む複数例で、上位10点がB獲得選手1着のみになった。Bラインが勝つという**ユーザーの指定していない前提**へ実質的に収束。
2. 別線が同じ位置に機械的に登場する。実力の弱い単騎追込まで「別線自力・捲り射程」として先行選手と同様に配置。
3. Bを取る際の競合抵抗・踏み出し・ライン追走を軽く見て、押さえ先行の負担がほぼ一律0.18。B後の差し・捲りを過小評価。
4. 本線B獲得、B番手差し、別線捲り、別線の番手差し等を**独立した道筋として生成せず**、全選手の点数を入れ替えるだけの箇所がある。競輪ファンが買い目から場面を想像できない。
5. 3番手以降のB取得を「番手発進」と表示するケースを含む戦術ラベルの不整合。

## 修正内容（v0.2相当、数値は未校正）
- 本人の脚質と戦術で別線を「自力の仕掛け候補」「自力に追走」「単騎追込・切替待ち」に分ける。単騎追込を捲り自力と扱わない。
- B獲得方法（突っ張り、押さえ、カマシ、番手発進、3番手以降からの追上げ等）と他線の抵抗の強さから、B選手の負担を再計算する。
- B選手押し切り、B番手差し、別線自力捲り、別線の番手差し、Bライン3番手の内突き、単騎追込のコース取りを独立した終盤経路として構成。各経路が発生するのは到達範囲、役割、追走、残脚などを満たすときに限定。
- 三連単の1・2・3着は全員が候補。Bライン入着という固定条件を設けない。
- 同じ1・2着から紐だけを10点広げる重複候補を軽く減点し、因果経路の異なる決着も比較対象にする。**別線を必ず入れる点数枠は作らない**。
- 不正な状態値（NaN）を検知するテストを追加。全選手の状態（位置・消耗・到達可能性）の整合性、単騎追込の戦法、3番手以降からのB獲得、9車の番手差し／外捲り経路を自動チェック。

## 残る課題
- **赤板→打鐘→ホーム→Bまでのラインの物理シミュレーションが未実装。** B時点の他線位置は条件付きヒューリスティックであり、捲りが最終ホームからどこまで進んでいるかを厳密に再現できていない。
- **牽制・捲りの成功／失敗と車間の推移**、4角までのブロック／外並走・中割り／番手の追走喪失については成立性制約が粗い。
- B候補の支持度・B後の決着スコアは校正済み確率ではない。公式確定Bデータと発走前入力が揃う対象の外部検証後に係数を見直す。今回の過去レースの結果に合わせた調整は行わない。
- 実測のBを与えたOracle-B検証と通常のB事前予測運用は完全に分離する。三連単3/5/8/10点の実際の捕捉率はこのレビューでは算出しない。
