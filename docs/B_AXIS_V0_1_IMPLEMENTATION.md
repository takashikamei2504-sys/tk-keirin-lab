# TK KEIRIN LAB B-AXIS v0.1｜要件確定・実装仕様

## 絶対原則
Bを取る選手を指定し、**その選手が最終バック先頭であるという条件の下で**、全員のバック時点の状態とゴールまでの決着を予測する。B選手・Bラインが1〜3着に入ることは要件ではない。別線の全独占を含む三連単は、B後の位置・速度・消耗・進路から成立する限り候補とする。

## 初版の機能
- 7車・9車の男子を対象。開催日・競輪場・Rから、共用公開出走表アダプターと発走前の資料収集を再利用。
- B獲得候補を全出走選手で比較。B率（出走回数とB本数）、S傾向、ダッシュ、ライン長・構成、特別選抜／特選／決勝／準決勝／予選／負け戦・選抜、地元、明示された本人コメント、ライン後位の上位期選手を比較する。地元・上位期は公開属性に限り、実在の師弟関係を推測しない。
- AIがBと獲得戦法を初期選択し、両者を画面で手動選択できる。先頭自力は突っ張り／押さえ先行／カマシ／早めの捲り、後位選手は番手発進／捲り／カマシを選択可能。
- B通過者を固定したまま、全選手の相対位置・Bに到達するまでの消耗・残脚・追走・別線の捲り射程を構成し、三連単を生成する。手動でBや戦法を変更するとB状態と全買い目を再生成する。
- 3・5・8・10点の上限設定。採用に値しない点を埋めない。各買い目に決着理由とモデル内の相対評価スコアを表示。
- iPhone Safari向けの独立画面 `b-axis.html`。JSON出力、コピー、保存済み発走前材料を使った7車・9車の動作例。
- 既存LAB、LAB LINE、ROIの予想エンジン・モデル・選別ロジックは上書きしない。共有するのは出走表・近況・本人コメント等の入力部だけ。

## 未校正である範囲
- B支持度は確率ではなく相対評価指標（合計100pt）。
- 相対位置、速度、残脚、車間、消耗はシナリオ上の指標で、GPSや実測脚力ではない。選手コメントや近況の欠損は欠損として扱う。
- 先輩・地元・勝ち上がりなどの重みは初期仮説であり、学習済み係数ではない。
- 購入判断・高配当重視の回収率最適化は別段階。現状の相対スコアからEVや的中確率を計算しない。

## Bが外れるときの評価
B予測成功率と、**Bが正解した条件付き決着**（オラクルB、結果Bを入力として与える研究用）を独立して測る。予測Bが当たらないレースは予想失敗として通常運用集計に含める。正解Bのオラクル結果からリアル運用回収率を主張しない。

## 詳細バックテスト
- 正解Bだけを「正解条件」として別入力。着順・払戻は買い目の生成に使わない。モデルの作成日時と資料時点を固定する。
- 上位3・5・8・10点の三連単捕捉率を7/9車、特選／決勝／予選／負け戦、戦法別に比較。切り詰め点数当たりのROI、1・2着捕捉率も別集計する。
- 旧LABの発走前固定予想と同時刻・同条件で比較する。過去レースの後付け再計算を過去の実測成績に混ぜない。
- 既存の探索用26Rは最終Bの記述統計に限る。発走前情報が揃うまで3〜10点の的中率は算出しない。

## テスト
```sh
npm run test:b-axis
```
発走前結果混入禁止、7車、8車不可、手動B変更、戦法切替、後位選手B、全出走者の保持、Bライン以外の1着候補を含むことを検証。
