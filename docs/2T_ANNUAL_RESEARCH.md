# 二車単 2025年の年間学習

2025年1〜12月の全月から採用できた男子9車2,004Rで、論文のネットワークを使ったTransformerとMLPを研究用に学習した。入手できた着順と過去成績から学習できることを調べる比較。V1は固定し、別データ・別重みで実施した。

| 車立て | 2025年学習適格 | 2026年1月検証適格 | 2026年2月以降テスト適格 |
| --- | ---: | ---: | ---: |
| 9車・今回の学習対象 | 2,004 | 189 | 850 |
| 7車・データ構築 | 19,925 | 1,679 | 7,615 |

9車学習範囲の実収録は1月4日〜12月30日の207開催日、全月に分布。テストは2026年2月1日〜8月25日の94日。テストは2月からの時間で先に分け、9月以降も監査したが、一意の上位着順と二車単払戻を確認できた9車は0件だった。2〜8月も欠測がある。発走前の保存記録と締切前オッズを揃えた評価は未実施。

## データ取得経路

楽天Kドリームスの出走表と結果を収録した公開月別CSVを、公開GitHubコミットと各ファイルのハッシュで固定。取得時と既存キャッシュ利用時の双方で原本を検証する。2024年は選手履歴にだけ使用し、2025年の教師レース数に含めていない。原本CSVの `date` には開催初日が入るため、レースIDの開催初日・開催何日目・レース番号から開催日を求め、日付や番号に矛盾がある場合は保留とした。出走車番と正解着順・二車単払戻の組合せが一致する通常結果だけで評価した。

入力は開催場・出走カードの級班と、選手の過去の着順から再構成した120日・同場・直近3走および10走の成績。選手は姓名と期別で照合し、曖昧な形式とレース内重複は保留。レース日から7日以内の結果をすべて特徴量から外し、同日・当該レース・将来の結果を入力に入れない。学習期間だけで正規化。アーカイブには発走前時点のカード原本と結果確定時刻がないため、開催日と入手済み結果から再構成した研究用データとして扱う。後日訂正された結果の過去時点の版は未確認。

月別CSVの `lineup` は予想印。実際の予想並びは楽天Kドリームスのレース詳細に別項目で掲載される。B・上位3着・二車単払戻はKドリームスとnetkeirinの結果に加え、全車番と氏名・netkeirinの登録番号を照合する独立スクリプトを実装した。並びを取得できても発走前の掲載時点を立証できる保存版がなければ、今回の学習には入れない。月ごとの9車先頭1Rを対象に計20Rを検査し、17Rで日付・全車番と氏名・B・上位3着・二車単払戻が一致し、公開画面の並びも抽出できた。氏名2Rとレース識別1Rの不一致は保留。残りのBは再開可能な段階取得の対象であり、正解ラベルを年間で一括取得した実績はまだない。

## 9車の実測

| 2026年の未学習850R | Top1 | Top3 | Top5 | 1着Top1 | Log Loss | Brier |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Transformer | 0.59% | 2.12% | 2.35% | 3.06% | 4.2773 | 0.98613 |
| MLP | 2.12% | 7.65% | 12.47% | 22.94% | 4.2493 | 0.98534 |
| 均等72通り | — | — | — | — | 4.2767 | 0.98611 |

Bの車番を仮定せず、1〜3着の観測尤度を各B候補で合算して学習。モデルの層構成はV1と共通だが、Bへの個別の教師信号、ライン、締切前オッズ、論文の全特徴量は含まれない。バッチ128、上限12エポック、車番入替推論8回、最良エポックは双方8。検証189Rだけで校正温度を選択し、学習後にテスト。V1と対象期間・入力・損失・推論条件が異なるため、50Rから2,004Rへの件数増だけの因果効果は未測定。今回の条件でTransformerに均等以上の精度は確認できなかった。MLPは均等より低いLog Lossだった。市場比較・EV・回収率は対象外。

## 再現

```sh
python -m two_t.annual_archive --cache /tmp/2t-monthly --out /tmp/2t-annual --size 9
python -m two_t.annual_train /tmp/2t-annual/annual-9.json /tmp/2t-annual-fit transformer --epochs 12 --repeats 8
python -m two_t.annual_train /tmp/2t-annual/annual-9.json /tmp/2t-annual-fit mlp --epochs 12 --repeats 8
python -m two_t.annual_crosscheck /tmp/2t-annual/annual-9.json --cache /tmp/2t-monthly --out /tmp/2t-annual/crosscheck-9.json
python -m unittest discover -s tests/two_t -v
```

PyTorch 2.8.0+cpu。学習済み重みは `2T_9car_2025_research_weights.zip`、データハッシュと校正前後の数値は結果JSONを参照。照合コマンドに `--batch 25` 等を付けると、同じログを使って未試行レースから順に追加できる。接続や照合の失敗は理由を残す。
