# LAB LINE V1.3.1 — 三分戦の標準的な初動順序

## 修正理由

V1.3では初手 A(前受け)→B(中団)→C(後方) に対して B先動き・C待機を通常候補として扱い、Aが再び主導権を取るまでの3段階を完結できなかった。自力を持つ3ラインの三分戦では、後方Cが不利位置解消のため先に斬り、Bが中団を取り直すために斬り、Aが先行力・ライン長を生かして再上昇する一連の動きを基本仮説にする。

## 標準仮説と分岐

- 周回：A → B → C
- 赤板、後方Cが前を斬る：C → A → B
- Bが前を斬り返す：B → C → A（Cの突っ張りがあれば不成立）
- Aが主導権を取り返す：A → B → C（Bが前を通した場合。Aの先行意欲とライン構成を条件とする）
- その後：後方Cのカマシ、Bの捲り、Aの先行残り・番手差し等を既存後半エンジンで評価する

## 例外と条件

- Cは先頭が自力を出せるなど、初動する合理性がある必要がある。追込のみの構成でCを自動的に上昇させない。
- B先動きは**禁止しない**。当該レースの本人コメント、Bの高い先行意欲と後方Cとの明確な差など、特別な理由を要求する。根拠不十分なら戦術評価を下げる。
- Cの初動へのAの突っ張り、Bの斬り返しへのCの突っ張り、最後のAの上昇不成立を別候補として保持する。
- 標準系列は競技規則や統計的に確定された出現率ではない。発走前の戦術仮説として扱う。
- 打鐘前の3回の位置入替を1局面に記録し、6局面の後半へ接続。複数ラインが横並走する厳密な時刻や速度は未計測。

## 検証

\`tests/line/positioning.test.cjs\` でC→B→Aの行動順、C突っ張り分岐、B先動きの例外的評価、Aの3車連係条件、隊列保全と原因追跡を確認する。従来のLINE・旧LABのテストも継続。

## 非対象

実レース映像からの自動的な位置取り観測・成功率校正は本修正では行わない。勝敗結果の後付けを禁止し、モデルIDをV1.3.1に更新して以前の保存予測は不変とする。
