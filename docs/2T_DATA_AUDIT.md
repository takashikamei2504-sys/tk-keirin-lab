## 時点と欠損

初期入力は既存の予想ファイルから `input` を項目指定で読み取る。既存予想の印・買い目・展開評価は学習・校正・市場比較のいずれにも入らない。配信公開時刻 ≤ カード保存時刻 < 発走を検証し、近走集計は本人IDの確認と公開 ≤ 取得 ≤ カード保存を追加検証する。入手時点を立証できた日のレースだけを対象とする。

| 特徴 | 今回の実装 |
| --- | --- |
| レース・選手 | 日付、開催格、級班、発走前の競走得点、脚質を入力。推論時には車番を入れ替え、元の対応に戻して平均する。 |
| ライン | 編成、ライン内位置、同ライン、直前・直後。編成が重複・欠損なら異常として扱う。 |
| 短期履歴 | 公式プロフィールの直近4か月集計と、保存済み直近3走着順・最大10走連続入着。競走得点の平均・H・Bは対応欄がある場合に使用。論文の120日厳密集計およびラインのB成否による分割は未再現。 |
| 未収録または条件未確認 | 年齢、事前証跡を満たす統一仕様のS、バンク寸法、表3.10の1着時付与点、1095日成績、過去走の獲得点・B、決まり手の内訳は今回の学習から外した。 |
| 欠損と数値処理 | 欠損ビットを追記。数値範囲は車立てごとのTRAINだけで学習し、VALIDATION・TESTに同じ変換を適用。学習で観測のない列は以後も欠損。 |

## 固定した時系列と精算

TRAINは2026-11-09まで、VALIDATIONは11-10〜12、TESTは11-13以降。7・9車を独立して学習し、境界をまたいで結果確定したTRAIN・VALIDATION行を遮断する。学習・校正用はBと上位3着が取れ、事故フラグが立っていない行。TESTの予測は全適格カードに対して生成し、評価時に照合可能な行を集計。確定オッズの論文比較のみ結果側の事故フラグで除外する。実運用精算には事故の事後除外を適用しない。

実オッズの主条件はWINTICKET販売締切のT−10分の時点を過ぎる前の59秒以内、配信更新が取得の5分以内、全組合せ、未確定かつ遅延なし。T−5分は別記録。いずれもEV≧1.5、1点100円。確定オッズは論文比較用に限る。二車単は提供元の100円当たり払戻を各的中券に計上する。同着は複数の支払対象を精算する。確認できた欠場券・中止は100円返還、結果未確定は保留。
