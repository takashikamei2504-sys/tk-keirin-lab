# LAB LINE V1.3.5 — 単騎の位置取りと先行の成立根拠

## 現象
豊橋12Rの4車A（1-7-5-3）、2車B（2-4）、単騎C（6）の画面では、単騎Cが中団を取り直すため再び前を斬り、そのまま最終ホームまで主導権を保持する仮説が選ばれた。

## 設計上の原因
3分戦の後方先動き→中団斬り返しという一般則を、単騎も含む3グループに無条件適用した。自力を出せることと、複数車ラインが控えている中で単騎が早くから主導権を取るべきことを区別できていなかった。

## V1.3.5
- 長い自力ライン（3車以上）がいるとき、単騎の先行志向の重みを抑える。単騎でも先行する本人の明確な事前意思があれば例外候補を許す（ただし成功確率ではない）。
- 通常の自力3分戦のC→B→A基本形を、単騎を含む隊列に機械的に当てはめない。
- 単騎は他ラインの上昇についていき、前を無駄に斬らず中団へ入る条件付きの仮説を生成する。追走能力・前団の受け入れが必要。
- 先斬りをした単騎がそのまま先頭に放置される経路、最終ホーム時点で単騎が長い自力ラインを前に引き受ける根拠のない経路を除外する。
- 単騎の捲り、好位狙い、後半に自力で動く選択は残す。競輪全般で単騎の先行を絶対禁止するルールではない。

## 注意
2026-11-04豊橋12Rと同型の4-2-1は合成の発走前データで再現。モデル修正はレースの実着順ではなく、発走前の合理性に基づく。画像の単騎主導権仮説を排除したことは実戦予想の的中精度を保証しない。
7車・9車、単騎中心、例外の事前コメント、旧LAB互換性とiPhone表示の回帰テストを継続する。
