# LAB LINE V1.3.6 — ライン編成の優位性と前受け側の反応

## 問題
豊橋12R（4車の深谷－吉澤－雨谷－川津、2車の伊藤－福島、単騎田中）のように、短いラインが上昇すれば強い4車ラインが理由なく前を譲る仮説を選んでいた。前を一瞬斬ることと、先行主導権を長く維持できることを区別する必要がある。

## 4車・3車・2車・単騎の構造
- **4車**：複数の後続による援護・後位の決着選択肢が多い。先頭の加速力は増えず、隊列維持・離れ・位置を失った際の巻き返しはリスク。
- **3車**：先行・番手・3番手の援護と機動性のバランス。先行型の意欲と後続の追走適性に依存。
- **2車**：短い隊列で動きやすく好位や捲りも選べる。3番手以降の援護がなく、長い強力ラインとの踏み合いに注意。
- **単騎**：進路・追走相手を選びやすいが、ラインによる援護がない。先行する場合は固有の戦術根拠を必要とする。

## 実装方針
1. 車数のみによる固定優劣は禁止。先頭選手の先行意欲・力量、追走する後続の能力、隊列の長さ、連結リスクを個別に計算する。
2. 強い3/4車が前受けで、短いラインが主導権を奪いに**押さえ**た場合、強い前受け側が無条件で譲る仮説は作らない。突っ張りと踏み合いの負担を比較する。
3. 短いラインが**一時的に斬る**仮説は残す。ただし、それは継続的な主導権ではない。強い元前受けが最終ホームまで無反応で待つ経路は除き、再上昇・カマシ等の選択を評価する。
4. 先頭の4車ラインの力量や先行意欲が弱い場合、または発走前の本人コメントで『引いて捲る』方針がある場合は、短いラインへ意図的に前を出す候補を残す。
5. 位置取りの記述に、ライン長、追走維持の潜在力とリスク、前を通す戦術的理由を含める。表示の数値は未校正の相対指標で、確率ではない。

## 検証
4-2-1、3-2-2、前受け弱者、本人コメントによる意図的な譲り、単騎、既存7/9車・競り・iPhoneなどの回帰テストを実行する。実際の豊橋12Rの着順や結果を特徴量へ混入させない。

## 制限
ライン長は自動的な先頭車の加速や物理的勝利ではない。本変更は発走前仮説の戦術整合性修正であり、実レース映像での位置取り一致率は未検証。
