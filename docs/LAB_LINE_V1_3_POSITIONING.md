# LAB LINE V1.3 — 位置取り判断エンジン

目的：初手→赤板→打鐘の位置取りを、単発の上昇・突っ張り／出させから、目的→行動→反応→第3ラインの追加行動→位置状態へ進化させる。旧LABとLINE V1.2の保存予測は変更しない。

## 実装

- `js/line/positioning.js`：12基本パターンの目的・行動・失敗条件（実際の位置取り履歴に戦術型と失敗条件を紐付け）、ライン別の暫定的な狙いを登録。前受け以外の初手順が未確認なら複数を比較する。
- `js/line/engine.js`：`early()` の分岐を新規モジュールに委譲。打鐘前に第三ラインが先斬りを引き受ける、または先行ライン後ろの中団を奪う仮説を作り、順序・前後の隊列・反応・理由を保存する。
- 突っ張られた上昇は中団を自動獲得しない。出させても後ろの位置は確定しない。先斬りは別線が引き受けるか継続的に解決しない限り成立しない。
- `js/line/view.js`：赤板→打鐘の判断の順序・目標・前後の位置を折り畳み表示。
- `js/line/build.js`：位置取りファイルのSHA256を含むV1.3のモデルID。予測時点を超える資料は引き続き不採用。

## 意思決定の制限

- 戦術の比較係数は仮説上の未校正値であり、確率・実測速度・実測消耗ではない。
- 速度変化、横並走の継続時間、細かな周回内の時間帯は測定していない。現行の6局面図は逐次遷移の最終隊列を表示し、すべての位置取り動作をコマ送りで正確に再現するものではない。
- 中団奪取の成否は能力・位置取り・抵抗の比較で判定する暫定規則。第三ラインの押さえも必要な上昇距離を実測していないため成立を保証しない。
- 同時捲り・競り・追走離れ等、後半の反応は既存のV1.2を継承。

## 検証

```sh
npm run test:line
node scripts/line_identity.cjs && git diff --exit-code -- js/line/build.js
node scripts/line-examples.cjs
```

専用テストは12パターン・初手順の代替・先斬り→別線先行・抵抗時の位置維持・因果履歴・全車保存・6局面とモデル識別を検査。評価映像・発走前固定保存と照合した位置取りの的中率はまだ測定していない。

## 実戦の位置取り評価（第4段階）

`js/line/positioning-evaluation.js` と `scripts/line-positioning-evaluate.cjs` により、発走前固定・ハッシュ一致のLINE予想と、別途確認された実レースの位置取り情報をモデル別に比較する。出典URL・公開日・取得日・検証フラグを必須とし、初手の順番、打鐘時点の順番、実際の動作順序を比較する。実戦位置取りの観測入力は `data/line_positioning_observations.json`。モデル別の評価は `data/line_positioning_evaluation.json` に保存し、既存LINEの結果集計ワークフローから更新する。現在は観測ゼロのため一致率を算出しない。テストは合成記録を用い、実測結果を装わない。

## 方針

まず位置取りの論理的な矛盾を減らす。着順や買い目の結果を使って赤板時点の判断を後付けしない。本V1.3は独立ブランチで検証し、旧LABのmainモデルを直接上書きしない。
