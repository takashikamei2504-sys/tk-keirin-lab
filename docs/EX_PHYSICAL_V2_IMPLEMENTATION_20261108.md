# EX物理成立判定v2 — 実装・比較・採用基準
更新: 2026-11-08

## 今回の完了対象
研究文書だけでなく、`js/tactical-transitions.js` をLABから呼べる独立実行モジュールとして作成し、`js/race-brain.js` に接続した。旧ロジックは `transitionMode:'legacy'` で保存。新方式は `transitionMode:'physical_v2'`、検証用に `physical_seat_only` / `physical_follow_only` もある。

### 状態遷移
1. **先行/前受け**: 戦術選択とカマシ・突っ張りの成立を別に扱い、現行の選択ロジックを維持（まだ元データに実測の局面ラベルがない）。
2. **先頭→番手追走**: 先頭の「ちぎり」と番手の「ちぎられ」を同一離脱事象の別視点として統合し、母数を足さない。これまで同一EX値で `track` と `keep` を2度補正していた点を解消し、追走成否に一度だけ適用。
3. **3・4番手**: 直前輪への追走リンクを保存。②が①から離れたとき、③④まで自動で離れたと決めない。未観測リンクは `not_observed` として残す。
4. **番手飛びつき**: 追走が切れただけでは番手へ移動させず、前方選手と後続の隣接関係・対抗ライン先頭/単騎・連続した加速仮説をゲート。空席維持 / 接近失敗 / 奪取成功を別状態に分ける。EX飛びつき成功率は試行の有無ではなく、試行後の成否の縮小補正に限る。競りEXを飛びつきの代用にしない。
5. **決着**: 展開経路に基づいて1・2着候補を生成するが、未校正の相対スコアは確率ではない。実測のブロック成功を創作しない。

## 過去レースでの比較
`scripts/ex-physical-historical-pilot.cjs` により、2026-11-01～07の発走前に保存した411レースを旧/物理v2で8点100円均等に比較。初期の「2分岐」プロトタイプでは従来68.4%→物理55.3%と回収率が低下した一方、1/2着捕捉は31.1%→33.8%、三連単的中率は18.7%→22.4%。これは物理ゲートが展開選択を大幅に動かす一方、資金効率を下げ得ることを示す。

その後「飛びつきを試みるか」と「試みたとき成功するか」を分離し、現在は3分岐版で再比較。評価結果は `research/ex_physical_ablation_20261108.json` に保存する。比較の全411レースで **2026-11-08取得開始のWINTICKET EX元値を過去へ遡及投入していない**。このため旧EXとの差や正式なEX勝率の有効性証明ではなく、*物理構造変更の検証*に限る。

## 導入ガード
本番通常表示は旧方式の買い目を採用し、`v14.html` の「物理v2で比較」ボタンで候補・状態遷移を切り替える。v2表示中は買い目コピーを無効化し、端末の発走前予想記録にも保存しない。新たなレースへ移動したときは自動で旧方式表示へ戻る。これはUIに表示できる実装済み機能であり、購入方針・ROI ENGINE・自動購入を変更しない。

`scripts/ex-ab-freeze.cjs` と `scripts/ex-ab-evaluate.cjs` は今後のEX付き発走前予想を「元モデルEXなし / EXあり旧構造 / EXあり物理v2」の同一入力・各8点で凍結し、払戻公表後に3方式を独立評価する。少なくとも200件・14日以上の発走前ペア、1/2着捕捉・回収率・高配当1件除外・日別下限を確認するまで、v2の購入反映は行わない。
