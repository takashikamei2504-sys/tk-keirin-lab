# Missing lineup handling

Primary source remains netkeirin. An empty lineup section on an eligible 7/9-field entry is recorded with known venue, class, field size, start and close. Retry occurs on the existing coordinated 30-minute runs while sales remain open. If primary lineup is empty, the existing public day feed may supply only ordered line positions, after same JST date, venue, race, start, fresh generation timestamp (within 6 hours), full exact rider ID roster and contiguous position checks. Primary partial/duplicate lineups are not overwritten. No guesses, no women or five/six-car extension, no late freezes. Fallback provenance is stored on the original snapshot. This source also lacked the three midnight venues' line positions on the morning of 2026-11-25, so the change does not guarantee immediate recovery. Independent engines consume the same input snapshot and are unchanged.
