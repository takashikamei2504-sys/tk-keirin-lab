# 競輪として成立する展開か：現実性ゲートの検証（2026-11-02）

## なぜ追加したか
11月2日防府12Rの旧LAB出力に、
- 太田海也の赤板→ホーム→3角での反復仕掛け（途中で脚と位置を回復した説明がない）
- 長島大介が後方から最終バックで突然先頭になる
- 竹内智彦がブロックに成功したのに太田が前進する
- 清水裕友が4番手から2着へ出る走路が説明されない
という不整合が見つかった。これは買い目の当否ではなく、展開自体を成立させる条件の問題。

## 実装した判定
`js/race-reality.js` は `story-brain.js` の各分岐に入る。
1. **ホームの先頭奪取**：大きく後方から即座に先頭へ移る分岐は、赤板から継続した踏み上げがある場合以外、本線候補から除外する。
2. **バックの先頭奪取**：５番手以降からバックで突然先頭を奪う分岐は、外並走の継続がない場合には禁止。仕掛け自体は不可能と断定せず、外に並ぶ分岐を残す。
3. **連続する捲り**：ホームで先頭を奪った直後にバックで抜かれ、再び３角で全力捲りするような分岐は、回復の局面を表現できないうちは採用しない。
4. **ブロック成功**：止めた選手は前へ移動させない。止め切れなかった分岐でのみ、前進させる。
5. **最後の直線**：最終コーナーの順位と継続攻撃・内の空き・縦踏みの有無から、追い抜き人数の上限をチェック。説明できない着順を候補から外す。ゴールで何人を抜くかを本文にも記す。
6. **保存則**：除外した分岐の重みは「未解決」に加える。買い目側に再配分して確からしさを偽らない。
7. **赤板の文言**：「カマシを試みた」と「主導権を奪った」を区別。

## これで「本当に実現可能」と証明できるか
**できない。** 現状の検査は「物語の内部で矛盾していないか」の保守的判定である。車間、時系列の速度、実際の空き走路、風、バンク傾斜、着差を数値的にはモデル化していない。強烈なカマシや高速捲りは短距離でも順位を大きく変えるため、仮の順位上昇上限で正しいレースを除外する可能性もある。

競輪公式の戦法ガイドは、突っ張り先行・カマシ先行・捲り・番手の牽制を区別する。競走規則は押圧・斜行・中割りなどの危険行為を規制している。LABの「ブロック」「中割り」は正式審判の安全・適法性判定ではない。

最終ホーム→バック→3角→4角→直線の「位置＋レーン＋時刻」、前の選手との車間、仕掛け開始位置、カメラ映像の観察を与えれば、現在の保守的な上限を走路・速度に基づく判定へ置き換えられる。現時点ではバンク実測や全レースの映像比較は未実施で、的中率・現実への適合度を証明したことにはならない。
