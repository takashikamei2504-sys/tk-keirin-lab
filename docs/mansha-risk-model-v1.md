# TK KEIRIN LAB 万車リスク推定 v1

## 結論
万車リスク推定は**通常のレース別エンジンとは独立した表示専用パラメータ**とする。万車専用の買い目エンジンは開発する場合もシャドー評価から開始し、本番エンジンの自動置換や買い目増加は行わない。

## 元データと対象
- 依頼期間：2026-05-08〜2026-11-07（184日）。
- 取得可能：2026-06-22〜2026-11-07（139日）。残る45日は資料なし。SS級など級班が既定形式から外れたデータおよびC級9車の1例は本推定の対象外。
- 評価対象：男子A級7車、チャレンジ7車、S級7車、S級9車の8,736R。3連単100円払戻10,000円以上を万車とする。結果・払戻欄は教師ラベルとしてのみ参照。
- 事前特徴：得点最高最低差、得点上位2人差、ライン平均得点差、4分戦以上、単騎人数、上位2人の別ライン、逃げ型の人数・配置、得点トップが先行型か。相関のある特徴を単純加算せず、正則化付きロジスティック回帰で評価。
- **過去の公開出走表の得点・並びが結果確定後に変更されていないかは未確認**。今後の前向き運用では発走前スナップショットを保存する。

|---|---:|---:|

- リスク上位25%判定（区分別9月の閾値）：**570R中201Rが万車、35.26%**。
- それ以外：**1,789R、24.20%**。上位判定は同区分の学習時万車率に対して1.24倍の万車件数だった。
- ただし上位10%判定は**239R中81R、33.89%**にとどまり、上位25%の35.26%より低い。極端な絞り込みは現時点では推奨しない。
- モデルの万車捕捉：**201 / 634 = 31.7%**。残り68.3%は上位25%に入っていない。万車を全て拾える仕組みではない。
- 上記はレースを絞った**発生率**。的中率・オッズ・期待値・資金配分・回収率を改善した証明ではない。

## LABへの活用
1. `auto.html` に「万車リスク（参考・β）」を表示する。推定万車率、同級班の基礎率、同区分の上位25%/10%判定、出走前特徴を示す。
2. 標準予想・レース別エンジン選択・買い目には一切変更を加えない。賭けの指示・推奨度と混同しない。
3. 発走前に予測確率とモデル版を保存し、レース確定後にログロス、Brier、上位25%捕捉、車券成績を評価する。
4. 万車専用エンジンは、既存のBライン展開仮説から**別ライン1着・2着を許す独立の候補生成器**としてシャドー検証を実施する。買い目の分散追加だけで満足せず、確定三連単を拾えるか、払戻オッズとEV、実回収率が改善するか比較する。
5. 最低1か月の発走前予想データで校正と回収率が再現するまでは、専用エンジンを標準予想へ自動採用しない。
