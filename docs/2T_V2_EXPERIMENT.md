# 二車単V2の入力・ライン評価の比較

対象は男子7車。2026-11-02〜09の異常なし・二車単的中組合せが一意の403レースで、1着と1着条件付き2着の選択モデルを学習した。説明変数を選手ごとに並べ、各段階で候補間を正規化して42通りの二車単確率を得る。L2係数は0.02で固定。休養・H・B回数や集計期間を確かめられない着度数は使用していない。モデルは研究用の比較候補。

| 版 | 1着側 | 2着側 |
| --- | --- | --- |
| 共通入力 | レース内の相対競走得点・脚質・ライン内位置・ライン人数 | 左と同じ特徴 |
| 近走追加 | 直近3走平均着順と欠損フラグを追加 | 同じ追加 |
| 同ラインだけ追加 | 共通入力と同じ | 共通入力に、勝者と同ラインかを追加 |
| ラインの前後も追加 | 共通入力と同じ | 同ラインか、勝者より前か、直後かを追加 |
| 近走＋ライン | 近走追加版と同じ | 勝者と同ラインか、勝者より前か、直後かを追加 |

過去データは保存済みの直近3走を使用。当日版は本人と発走前時刻を照合済みの出走表から、開催日より前に終了した直近開催の3走を使用した。その開催に3走が揃わなければ欠損扱い。これにより並び順の違いの影響は受けない。11月17日は154選手出走枠のうち135枠（87.7%）で利用できた。開催が2走以下または4走以上の場合、当日版は保守的に欠損とするため、過去データより採用条件が狭い。

## 比較結果

Log Lossは小さいほど良い。11月13〜16日はすでに原因診断で参照した期間。11月17日は、旧データ期間の翌日の発走前保存カードから事後に再計算したもの。研究モデルの当日発走前予測としては扱わない。

| モデル | 11/13〜16の二車単 Log Loss (199R) | 上位3点 | 11/17の二車単 Log Loss (22R) | 上位3点 |
| --- | ---: | ---: | ---: | ---: |
| 均等 | 3.7377 | 7.14% | 3.7377 | 7.14% |
| V1 Transformer | 3.7385 | 5.03% | — | — |
| 共通入力 | 3.1758 | 36.68% | 3.2577 | 31.82% |
| 近走追加 | 3.1610 | 37.69% | 3.3149 | 31.82% |
| 同ラインだけ追加 | 2.8790 | 46.23% | 3.0879 | 45.45% |
| ラインの前後も追加 | 2.8592 | 46.73% | 3.1684 | 36.36% |
| 近走＋ライン | 2.8441 | 48.74% | 3.2196 | 40.91% |

11月13〜16日の確定オッズ市場は同じ199レースでLog Loss 2.6155。11月17日の締切10分前オッズが揃った5レースでは、市場3.3685、共通入力3.6529、近走追加3.6802、近走＋ライン3.7180だった。発走前のV1予測と新候補の両方を採点できる4レースではV1が3.7370、近走＋ラインが4.1472。22レース全体でのV1比較、EV・収益性、および9車は未評価。11月17日の近走＋ラインは上位3点9/22、最上位1点0/22。

2着側のライン項目を追加すると、実際の1着を与えた条件付き2着Log Lossは過去199Rで1.5815→1.2646、11月17日の22Rで1.4458→1.3505。近走追加だけの改善は日によって一致しない。V1の置き換えの判定は、今後の発走前保存と独立期間で実施する。

## 追加の切り分け

- 共通入力から「同ラインか」だけを加えると、二車単Log Lossは199Rで0.2968改善した。前後関係まで追加した場合の改善は0.3166。4日すべてとS級・A級・チャレンジの全区分で改善した。前後込みの版では134/199Rで的中組合せへの確率が増えた。日単位の再標本化で差（新−旧）の探索的95%範囲は−0.405〜−0.252。4日しかないため確証とは扱わない。
- 11月17日の再計算22Rでは、同ラインだけ追加した版がLog Loss 3.0879・上位3点10/22で最良。同ラインだけ追加した版に比べ、前後まで足すとLog Lossが0.0804悪化した。前後の表現や近走入力を加えた効果は両期間で揃っていない。
- 同ラインだけ追加した版は、11月17日の実際に同ラインで決まった12Rでは共通入力から0.5111改善、別線が2着に入った10Rでは0.2399悪化した。過去199Rでも同ライン128Rで0.6482改善、別線71Rで0.3366悪化。結果による層別は原因診断用で、発走前の選別に利用していない。

5レースに限ると、新候補の市場との差は1着段階にあった。2着側の値は、実際の勝者を既知とした原因診断。全レースへの一般化や市場・収益の優位性は判断できない。次の独立期間は「共通入力」と「同ラインだけ追加」を固定し、発走前に予測を保存して比較する候補とする。

## 再現

- 保存済みV1の根拠資料 `2T_TRANSFORMER_V1_EVIDENCE.zip` 内の固定データと予測を利用する。読み込み時にSHA-256を照合する。
- 観測台帳は `0e642f9628827ac0d191860920a07a6f76aa5574`。台帳の特徴量・結果・オッズを既存の監査手順で照合する。
- 研究実行環境は Python 3.12・NumPy 2.3.5・SciPy 1.17.0。予測ごとの42通りと総和1を検査する。

```sh
python -m two_t.v2_experiment PATH_TO_V1_EVIDENCE.zip --ledger PATH_TO_LEDGER \
  --as-of 2026-11-17T18:16:03+09:00 --out /tmp/2T_V2_EXPERIMENT.json
```
