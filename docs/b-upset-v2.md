# B-UPSET V2

独立画面 `b-upset.html`、エンジン `js/b-upset/engine.cjs`、分類 `patterns.cjs`、評価 `evaluation.cjs`。既存のLAB・LINE・ROI・万車シャドーの保存記録は読み取り専用。モデル識別は `node scripts/b-upset-identity.cjs` で依存コードまで含めて固定する。

## 発走前の分類と仮説

Fはライン先頭の得点×0.60＋ライン内最高得点×0.25＋番手得点×0.15による力量1位。市場人気順位は取得していない。式・情報時点・出典・固定ラインIDを保存する。F以外で先頭が逃・両の各ラインに対し、押さえ・突っ張り・カマシ・早めの捲りを独立生成する。追込型のみの先頭は主導権候補から除外する。

既存B-AXIS v0.6の独立展開生成・追走・番手争い・別線仕掛けとEXの時刻検査を再利用する。全選手の保存、B先頭条件、累積消耗の単調性、無理なライン飛越しを監査し、同モデルの到達距離・追走・進路条件を通った三連単だけを採る。これは相対状態を使う戦術モデルであり、測定した速度や校正済み確率ではない。B本数などの未取得値は入力境界で欠測として扱う。

A〜GはBBB・BFB・BBF・FBB・BFF・FBF・FFBの完全一致。Xを含みBも残るものをH1/H2/H3、Bが残らないものをZにする。三連単ごとに各ラインの役割別着位、Xの実所属、B戦法、追走離れ・競り想定、個別の4角〜ゴールを保存する。Zは購入対象外として記録する。

研究比較はA〜D限定、A〜H拡張を各最大10点、全候補購入と3着総流しを点数上限のない比較研究として出す。全候補・総流しは購入推奨には使わない。各パターンへの均等配分は行わない。

## 購入価値

購入推奨は当初0点。B-UPSETの校正済み確率と本人確認済みの発走前オッズが揃い、同一モデルの評価期間・収益性が確認できるまで見送り。`selectValue` は異なるモデルの確率、締切後・確定オッズ、古い見積りを拒否し、期待値が1を超えるものを最大10点・各100円にする。既存ROIの確率をB-UPSETの確率に流用しない。初回検証では収益優位性を認定していないため、本番でこの選別に渡す校正データは存在しない。

## 前向き保存と実B

`scripts/b-upset-daily.cjs` が既存の発走前保存カードと日別の公開出走表を読み、処理完了時も発走前である場合に新しい専用ファイルを排他的作成する。初回の保存以後は上書きしない。入力・出力ハッシュ、親予想のハッシュ、モデル、F/B、買い目と根拠を保存。実際にBを取れたかと三連単的中を分離して評価する。既存予想との重複を記録し、将来の購入統合時に重複を除くためのキーを保持する。

実Bはチャリロトの結果表のS/B列からだけ取得する。車番・選手名・着順の一致が必須。配信元にないBを着順や決まり手から補完しない。公表表のB欄を独立照合した公開データであり、公式原本の認定とは区別する。日次では1回最大16会場日を取得し、未取得分を後続実行で補完する。

専用Actionsは定期実行と既存予想・結果収集の完了時、関連コード更新時に動く。発走前保存がなかった過去レースには予想を遡及追加しない。標準予想の保存が遅れた場合も日別出走表から独立して作成する。結果も専用の検証済み保存に蓄積して前日分を再取得する。新モデルの成績は`data/b_upset`だけに書く。

## 過去検証

`node scripts/b-upset-study.cjs`。2026-05-08〜11-07の184日を要求し、現在の公開アーカイブから取得できた139日・有効8,786カードを棚卸しする。997Rは各日・級班車立て別にレースIDのSHA256順で2件を固定抽出した展開再現。結果・払戻・実Bで抽出しない。基本出走表だけで再現し、現在のEXや選手資料を過去へ入れない。アーカイブ出走表は実際に当時固定されたB-UPSET予想ではないため、前向き実績と分離表示する。

期間境界は9月1日と10月1日。過去の探索ですでに見た期間を含むため、未使用の未来テストと称さない。新たな発走前予想で採否を判断する。全サンプルに対する回収率を計算し、実Bが非有力ラインだったレースだけの事後抽出ROIは採用しない。別途、11月1〜7日に実Bを照合した442Rのうち非FがBを取った決着構成233件を記述集計する。

同一レースで既存LABとLINE双方の保存記録がある31Rも比較する。既存方式は当時の点数、B-UPSETは最大10点のため平均点数を併記する。実オッズ・適合校正のないEV方式は0点として明示する。最大ドローダウン、最大1件・上位5件の払戻レースを投資ごと除いたROI、的中率・点数を出す。

テストは `node tests/b-upset.test.cjs`。7車210通り・9車504通りを網羅し、HとZ、2車ライン、時刻・ハッシュ・結果の混入、確率モデルの不一致、B欄欠測を検査する。iPhone画面はChromium/WebKitで確認する。
