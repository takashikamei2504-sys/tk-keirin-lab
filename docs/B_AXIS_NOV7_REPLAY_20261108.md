# B-AXIS 2026年11月7日・全58レースの実測B／三連単精度検証

**評価日：2026-11-08。**
この検証は、2026-11-07のレース以前に保存した出走表／選手材料を、**当該レース後に開発された**B-AXIS v0.2とv0.5で再計算した後日評価であり、「11月7日にv0.5が予測を公開していた」という意味ではない。

## 1. 取得・結合方法
- 既存LABの \`data/lab_evaluation.json\` で11月7日58レースを抽出。
- 個々の \`data/lab_history/2026-11-07/p-*.json\` を読込み。保存時刻が発走時刻より早く、同じレースIDと保存日時が一致し、\`pre_race=true\` のものだけを採用。
- チャリロト結果表から各レースの実際のB車番を\`S/B\`列の **B印** で抽出。1着〜3着車番を別途抽出し、既存結果フィードの確定三連単と照合。
- **58レースが全件成功、Bの欠損、確定結果不一致、発走前スナップショット不備、モデル例外はすべて0件**。
- 使用会場：京王閣7R、熊本11R、高知10R、四日市11R、小倉7R、福井3R、弥彦9R。
- \`input\` に結果、実測B、払戻を含めず、\`build(input)\` でAI Bを選択。別途\`build(input,{bNo:actualB})\` で後知恵の正解B条件付きを評価する。
- 公開ソース： https://www.chariloto.com/keirin/results/48/2026-11-07 （同形式で各会場）と結果公開フィード、該当日付以前のLAB保存データ。Bの推定値を正解Bとして使用していない。

## 4. B選手・Bラインの事実関係（実測58R）
- **B獲得者が1着：16/58R（27.6%）**。
- **B獲得者が3着以内：31/58R（53.4%）**。
- **B所属ラインの誰かが1着：30/58R（51.7%）**。
- **1・2着がB所属ライン：20/58R（34.5%）**。
上記は今回抽出された58Rの割合であり、全競輪の母集団統計ではない。**Bラインが勝つとは限らない**という開発原則を実数で確認できた。

## 5. 予測が外れた仕組み
- B獲得者が正解なのに5点以内で外れたのは45R。このうち**31Rでは実際の1着車番が上位5点のどれにも入っていない**。8Rは1着は含むが1・2着ペアを外し、6Rは1・2着ペアまで含むが3着を外す。
- したがって直近の急務は、3着紐を増やす前に**B以降の1着勝ち筋を包括的に分岐**し、とくにB先頭の押し切り・別線の番手飛び付き／切替・牽制失敗を取り入れること。
- **四日市12R**：正解B①中野慎詞、実際1-2-4（16,990円）。AIもB①を選んだのに、上位10点は⑦和田圭の番手差しと③岩本俊介の外攻勢へ偏り、実際の勝者①を1着に含まなかった。**古性②が和田⑦を捌き、脇本④が中野後位へ嵌る**展開を構築できない。公式記事・レポートでもこの攻防を記載。
- **四日市9R**：正解B①、実際7-1-5。B車番自体は当て、7-1のペアも含めたが、⑤の3着を優先できず7-1-4を選択。
- **四日市11R**：正解B④、実際1-7-3。上位10点では1-3-5を筆頭に、1着①は当てつつ別線後位⑦の2着を軽視。
- **四日市2R**：正解B⑦、実際7-8-2（212,400円）。B⑦を事後指定しても、⑦の番手③が差す筋を重視して1着⑦の残りを予測できず。9車の高配当レースで致命的。

通常v0.5の全58R、毎R均等に5点×100円：投票額29,000円、的中払戻合計26,930円、仮計算回収率**92.9%**。10点×100円：投票額58,000円、的中払戻40,100円、仮計算回収率**69.1%**。これは後日完成したモデルを過去のレースへ当てはめた数学的な評価で、実売買・将来の回収率ではない。100倍以上を計13R全て取り逃しており、50〜100倍を狙う設計も未完成。

正解Bを事後指定したOracle回収率は通常購入可能な成績でないため、購買判断には使わない。

## 7. EX・選手別過去入着実績の寄与（この検証の重要な限界）
- WINTICKET EXの千切り・千切られ・突っ張り・カマシの選手別実測件数は**まだ0件**で、この58R再計算にも投入されていない。
- 広域ライン別実績アーカイブは2026-11-07までの結果を含むため、11月7日のレースに利用すれば未来情報混入になる。B-AXISは日付ゲートでこれを**使用していない**。
- したがって旧版から+1Rという数字を「EXの千切られ率で精度が向上した」と説明することは**できない**。改良の効果の中心は既存の個別追走・戦術候補の再設計であり、EXの実測値効果は未測定。

## 8. 次の優先開発課題
1. **9車のB後の番手奪取・飛び付き・競り・捌き・切替**を取り扱う。B番手が逃げ切り差しの定型にならないよう、外線の前受けや内側進入、番手奪取を確率的な状態分岐へ組み込む。
2. B先頭の押し切りとB番手差しの優劣を、選手固有の実力・疲労・ラインの進入・他ラインの介入可否から算定。**Bは勝つ／負けるのどちらにも決め打ちしない**。
3. 他ライン追撃による1着・2着の選択肢を先に検査し、その後に3着に残脚・内進路・単騎を配分する。
4. 7/9車、S級/ A級、3車・4車ライン・単騎の戦術成立性を分けて検証。
5. 新旧の正解Bと通常Bの両方で、異なる未来日付の5点捕捉率・高配当帯捕捉率を比較し、改善時のみ採用。
