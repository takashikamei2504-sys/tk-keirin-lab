# B-AXIS v0.3｜実際のB・着順・公式レポートによる検証と攻防モデルの実装

## 目的
「Bラインが勝つ」ではなく、**選択した選手が最終Bを取ることを条件に全選手の着順を推理する**B-AXISの完成度を評価し、三連単を3・5・8・10点へ圧縮する。2026-11-06のB通過者・確定組番と**発走前に保存された入力**26Rを照合する。実測Bは実験用Oracleモードにだけ渡す。

### 検証済み資料
- 26R：11月6日の別府7R、熊本7R、四日市GIII12R。公開結果とLAB保存履歴の車番、確定組番、保存日時を結合。元出走表・並び・選手・発走前データは歴史スナップショット。
- 公式記事8件の明示的事例：2026年7月17～18日のサマーナイトフェスティバルGIIレポートから、ブロックの影響、追走離れ、切替、内進路を注記した。**ランダム・全数抽出ではないので、全競走に対するブロック成功率・追走離れ率は算出不可。**
- JKA公式レポート初日： https://keirin.jp/pc/dfw/portal/guest/report/graderace/summer/2026/report_1.html
- JKA公式レポート2日目： https://keirin.jp/pc/dfw/portal/guest/report/graderace/summer/2026/report_2.html

### 10点で見逃す原因
- v0.2：26R中14Rが三連単捕捉。12Rの取り逃しのうち、1・2着までは正解5R、1着のみ正解5R、1着から異なる2R。
- v0.3：26R中13R捕捉。13R取り逃しのうち、1・2着まで正解5R、1着のみ正解4R、1着から異なる4R。
- 特に**1・2着を捕まえても3着が違うレースは両方式5R**。3着の後続の伸び・単騎・別線のコース取りをさらに評価するのが重要。

## B後の攻防で今回新しく考慮した機序
1. **他ラインの攻撃**：B時点の相対位置・残脚・外並走・接近可能性から反撃可否を判断。B選手／Bラインの勝利は条件としない。
2. **牽制可否**：B番手が連結を維持しているか、攻め手が外から牽制可能な範囲にいるかを判定。離れた番手が無理にブロックするシナリオを排除。
3. **牽制成功と失敗**：成立可能なときのみ両経路を比較。公式レポートの実例では、牽制を受けても再加速して勝つ、牽制により第三の選手の内が空く、という別々の経路が存在する。
4. **追走離れ**：先行が加速した場合の後位の追走難度と相対車間を照合。離れた後位選手を、密着した番手・捲りの追走者として評価しない。
5. **別線番手差し・内突き・追上げ**：B側が失速し、別線の1・2・3着独占に至る経路も許容。

## 公式事例の扱い
登録した公式レポート8件の内訳は、ブロック／牽制の記載4件、追走離れの明記2件、連結維持1件、内からの抜け出し1件。

4件の牽制例では、3件は相手の攻勢が阻害された記述、1件は一時的に妨げられても後で勝った記述。これは記事の**選択事例内の分類**にすぎない。ブロックの試行総数が分からず、無条件の成功率として「3/4=75%」をモデルに入れることは禁止。

追走離れ2件も、追走機会の母数がないため「離れ率」ではない。

## 成績報告・統計の境界
- 26Rは単日・7車が非網羅で、公開結果配信に依拠する。結果データは公式原本との独立全件照合は未完了。
- v0.2とv0.3は当該レースより**後に開発されたモデル**。発走前入力は凍結されていても、過去結果の知見が開発へ影響している可能性を排除できない。将来収益率・出走前実測モデルの成績を主張しない。
- 相対追走・牽制強度は選手の事前情報に基づく**未校正のモデル指標**。公式記事の事後イベントは実験の参照資料に限り、発走前モデルへ直接投入しない。
- 100円均等購入の払い戻し計算も行っているが、出走時刻の実際の購入オッズではないためライブROIとして採用しない。

## 今後の検証ゲート
1. 記事からの無作為な事後抜粋ではなく、対象レースを先に選び、**全ての牽制試行・追走機会**を公式映像等で分類した完全標本を収集。
2. ブロックの防御・被牽制・成功・失敗・一時的影響を別項目とし、分母・失格等の除外基準を明記。追走は成功／離れ／復帰を分離し記録する。
3. 評価対象の日付は、係数を決めた期間より後に固定し、7車・9車、ライン長、地元、決勝／初日特選／負け戦を層別。自律的にBを選ぶ通常モードと、実測Bを与えるOracleモードは分離。
4. 3・5・8・10点の三連単捕捉率だけでなく、1・2着ペア捕捉、3着取り逃し、点数コスト、的中倍率帯とオッズ時点別回収率を比較する。**5点で従来版を上回り、別日でも再現できるまで、新方式は本命へ昇格しない。**
