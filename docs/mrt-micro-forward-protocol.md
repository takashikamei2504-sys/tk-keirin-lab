# MRT MICRO 前向き検証プロトコル（2026年11月24日）

本研究は、現行MRT V3と、本家Mr.Tの少額買い目構造を学ぶ独立した第三着・1/2着ペアモデルとを、**発走前に凍結された条件だけ**で比較するものです。実際の投票は行わず、モデルの本番採用は承認制とします。

## 入力・モデル
- 現行モデルMRT_V3_7126の固定スナップショット（元の三連単、金額、登録番号、取得・生成・締切時刻）を基準Aにする。本番モデル・サイト・既存の買い目に一切変更はない。
- 研究用の別モデルは2026年6月30日までの本家予想から教師データを固定し、100〜300円の買い目に登場する1/2着ペア、次いでそのペアの3着を独立学習する。登録番号は照合用途だけ。
- モデル入力は出走表、ライン、競走得点、B・捲り・差し等の発走前データ。事後の結果、払い戻し、本家の当日印・記事・購入情報は使用禁止。
- 教師データは遡及収集されたため、学習元の過去入力は独立な発走前検証データではない。出力は教示傾向スコアであり、校正済み三連単的中確率や期待値を意味しない。リアルタイムオッズ取得なし。

## 固定資金と選択案（1R、100円単位）
| 方式 | 仮想予算 | 買い目 |
|---|---:|---|
| A 現行 | 10,000円 | 元の自動予想と金額を変更せず比較 |
| B THIRD | 10,000円 | 現行上位3ペアに対して3着モデルから新しい8点以内（1ペア最大4点） |
| C PAIR | 10,000円 | 現行にない1・2着ペアの3着候補を最大8点（同一ペア最大2点） |
| D HYBRID | 10,000円 | Bから7点以内、Cから8点以内（それぞれペアごとの上限あり） |
| E CAP/SKIP | 0円または5,000円 | Dの候補を上限5,000円に縮小し、ペアの最大選択信号0.15未満、追加候補なし、現行が51点以上の場合は購入見送り |

候補追加は各100円。追加資金は元の購入額から比例控除、元の全買い目も最低100円を維持。最大購入額・追加上限・見送り条件は評価結果を見て自動修正しない。Eの0.15は教師の買い目選択信号に対する試験値で、EV閾値ではない。

## 真の前向き検証の成立条件
1. 元のV3も新研究案も、販売締切より前に作成・保存完了。開始日より前の追加保存は禁止する。
2. レースID＋モデルコード・データのプロトコル指紋を含め、研究予想はレースIDごとのファイルとして追記専用。再実行しても上書きなし。
3. 予想の対象は男子7/9車のみ。モデルの発走前入力には結果・当日の本家予想を持ち込まない。
4. 元結果台帳に正式確定、登録番号一致、三連単払戻が得られたレースだけ採点。同着は全払戻の合計。未確定・欠車・取り消しは評価除外として記録。
5. 7/9車、級班、日付別、購入・見送りレース数、点数、的中率、金額、収支、ROIを比較。特に1/2着ペア一致と3着紐抜けを区分。
6. 高額払戻が生じた上位1・3・5レースを5方式共通で除外し、感応度評価。結果に合わせてルールを遡って変えない。
7. 200レース以上かつ28暦日以上で人間による採用判断の資料を作成するだけで、モデルは自動的に切り替わらない。
