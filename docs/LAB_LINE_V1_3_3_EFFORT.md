# LAB LINE V1.3.3 — 努力消費・追走利用・再加速の意思決定

## 位置取りの原則
脚力は有限。位置を変えられることと、変えることが得であることは異なる。中団を得たラインは、独力で再び斬るための負担と、好位を保持する価値を比較する。先行志向が強いラインでも、後方ラインの上昇に乗ってからカマシを狙う戦術を候補化する。

## 実装
- js/line/effort.js：相対努力（spent）・加速回数（surges）・別線利用（usedDraft）の履歴。斬り・押さえ・突っ張り・カマシなどの再加速に追加負担を設定し、他ラインの風よけを利用する追走は低負担にする。
- js/line/positioning.js：赤板〜打鐘の連続動作ごとに努力コストを記録。最終ホームで後方Aが実際に外を上昇した候補に限り、次の反応を検討する。
  1. AがCを外から交わす。Aはまだ前方Bを追い越していない。
  2. CがAの後ろへ入り、追走によって風圧負担を低減する。
  3. Cが追走後にカマシを開始し、前団外へ並走する。直ちに先頭へ移動はしない。別ラインの抵抗は後段で比較する。
- js/line/engine.js：累積努力・加速回数・発進位置と残りの持久力を後半の仮説評価に反映する。
- js/line/view.js：iPhoneの6局面に、相対負担・加速回数・別線利用の回数を表示する。

## 反証
- Aが動かなければ、Aの動きを利用したCのカマシは不成立。
- Aが中団Cを外から交わせなければ、その後ろへの追走も成立しない。
- Cの追走適性とカマシ能力が一定未満なら生成しない。
- 再加速を重ねると相対的な追加コストが発生。相対スコアであり、実測ワット数や身体の残存エネルギーを意味しない。

## 検証
単体テストで再加速追加コスト、追走の省力化、A→Cの行動順序、動かなかった場合の不成立、局面の位置関係と努力履歴を確認。予想時点より後のレース情報を事前仮説へ混ぜない。

## 未実装
実測の速度・加速度・風・疲労量を扱う物理モデルや、レース映像との位置取り照合は未実装。後日確認する実戦資料と発走前に凍結した予想との比較で改善を検証する。
