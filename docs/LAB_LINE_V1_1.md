# LAB LINE V1.1 — 指示書対応の拡張

次の拡張：[V1.2の評価・逆転条件・可変点数](LAB_LINE_V1_2.md)。本書はV1.1時点の記録。

対象：`LAB_LINE_ENGINE_V1.1.0`。旧LABの予想コード・公開画面・基準モデル・発走前保存を変更しない。LINEの旧版予想も、モデル識別子ごとの最初の保存を維持する。

## 変わった点

| 指示書の要件 | V1.1の実装 | 検証 |
|---|---|---|
| ラインを起点に戦術を生成 | 並び、先行一車、二分・三分・細切れ、単騎、積極型競合、捲り型競合、2〜4車連係を解析 | 同じ選手の構成変更、同じ構成の特性変更 |
| 全ラインの連動反応 | 前受けの抵抗／受入れ、斬った後の主導権引受け、待機、別線利用、第三ラインの反撃 | 全候補の6局面で選手重複・消失を検査 |
| 複数ラインの同時捲り | 二つの独立した外進行を保持。前団・二列目・三列目を同時表示。守備の応答順も比較 | バック時点で外二列が実在する候補を検査 |
| 不発後の立て直し | ホームの不発→バックの立て直し／位置と裏付けが足りる場合の再仕掛け | 前局面の不発がなければ再攻撃を置かない |
| 追走離れからの回復 | 加速・追走特性・負担から分断。後の局面で回復し、残る隊列の末尾へ復帰 | 元の番手への無条件復帰を禁止 |
| 競り・飛びつき | 当該レースの本人コメントから、先頭と相手を特定できる競りを解決。番手防衛／奪取／継続を分岐 | 競り先不明は創作せず、明示的な未解決として停止 |
| 切り替え | 直前ラインの番手空席を確認して切り替え。移籍先では先頭の直後へ配置 | 単騎をライン末尾へ誤追加する旧挙動を修正 |
| 牽制と内進路 | 成功・部分成功・失敗、両者の負担を区別。実際の牽制で開く内進路から近い選手が進出 | 牽制なしの内進路、後方からの突然の飛躍を棄却 |
| 選手の戦術的個性 | カマシ・捲り・早めの捲り・引く傾向・立て直し・内進路を別特徴量に分離 | 本文の方向・時点・信頼度を使用。記事の件数だけで加点しない |
| 本人コメント | 今回の意思は候補生成と合理性の小幅補正。調整・回復の総合所見も接続 | コメントを実行済みの証拠へ変換しない |
| 最重要判断軸 | 有力な戦術群から軸案を選び、本線案と対抗案の差を確認。区別しない軸は本線確定前に再検討 | 最大の分散があっても主な2候補を区別しない例で再検討を確認 |
| 説明と実計算の一致 | 本線・対抗それぞれの実使用特徴量、出典、軸別の差、軸案の再検討過程を保存・表示 | 数値と計算項を照合。対抗の不利が主因なら、その旨を明示 |
| 決着・買い目 | 先行負担、番手の追走／牽制負担、直線の伸びを比較。3着の合理的範囲を固定3人にしない | 重複なし・上限10点。別筋は独立した整合性検査済み仮説から生成 |
| iPhone表示 | 全選手を3段に配置し、捲り・競り・内進路・追走離れの区別と連結を表示 | 同一局面で全選手を描き、円の重なりを禁止。320／390pxを検査 |
| 対抗の図と買い目の接続 | 対抗・別展開も6局面図を遅延表示。各買い目から対応する仮説へ移動 | 本線の図と別筋の買い目を混在させない |
| 発走前情報と保存 | 出走表・記事・本人コメント・競り・環境観測に入力時点の境界を適用 | 発走後・入力時点後の情報、古い風を不採用。既存保存は上書きしない |
| 新旧比較 | 同じ保存済み発走前入力でLINE 1.0／1.1を比較。画面の旧LAB比較も継続 | `reports/line/v1.1-checks.json`。結果は入力しない |

## 追加・変更ファイル

- `js/line/state.js`：所属・並走・内進路・分断の投影、局面の整合性検査。
- `js/line/interactions.js`：反撃、失敗、回復、再仕掛け、競り、内進路の遷移。
- `js/line/selection.js`：有力候補比較、判断軸の再検討、対抗との実際の差と反証。
- `js/line/conditions.js`：出典・時点を検査したバンク／風の観測を小幅な比較に使用。
- `js/line/input.js`：戦術特徴量の分離、実測値の出典、本人所見、競り先解決、情報時点の制限。
- `js/line/engine.js`：上記を6局面の探索・決着・買い目へ接続。
- `js/line/view.js`・`app.js`・`line.html`：3段の図、対抗図、仮説リンク、判断差と再検討の表示。
- `scripts/line_identity.cjs`：新しい依存モジュールを含めたモデルのSHA256。
- `scripts/line-checks.cjs`：保存入力による旧LINEとの比較要約。選手データの新たな公開はしない。
- `tests/line/interactions.test.cjs`：追加した相互作用・因果条件・図・時点を統合検証。

## 重要な修正

同じ隊列でも、早めの仕掛け・不発・回復は同じ状態ではない。候補統合に負担、斬りの目的、競りの経過、仕掛け成否を含め、戦術群を順に保持する。成功した仕掛けの初手違いだけで探索枠を埋めない。

外並走の選手を「内側の隊列の最後尾」として3着評価する旧問題も修正。外の選手は攻める相手との位置関係で評価し、未測定の車間や速度には変換しない。ゴール図の4番手以降は「後続」とし、評価していない最終着順を断定しない。

## 検証の再実行

```sh
npm run test:line
node scripts/line-checks.cjs
node tests/line/browser.cjs
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
```

A〜Hに加え、同時捲り、競りの帰結、立て直し→再攻撃、追走回復、内進路、判断軸の再検討、図の全選手保持と重複、環境観測の時点を検査する。新しい専用CIで動作画面も確認する。

## 現在の限界

有限のルール探索であり、全戦術の網羅や実際の最適判断を保証しない。比較係数・バンク／風の補正は未校正。速度・車間・実測消耗は作らない。確率・成功率・購入価値として表示しない。

バンク・風は、発走前に取得した出典付き観測がある場合だけ使用する。`data/line_conditions.json` の共有観測を会場・レース・時点で照合して自動接続する。現時点の共有観測は空であり、既存のライブ取得で供給されない観測は未取得のまま。KEIRIN.JPの公開ページ内APIはrobotsで自動取得が許可されていないため、新たな自動収集には使用していない。競り先が特定できないコメントも自動補完しない。

個別の競りの細かな攻防や進路が不明な場合は条件付き仮説として残す。実レースの結果から発走前の根拠を後付けしない。
