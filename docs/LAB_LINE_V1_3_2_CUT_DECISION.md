# LAB LINE V1.3.2：好位維持と主導権引受けの分離

## 修正対象
先斬りが保留された際、旧 `engine.js` の `launch()` はほかの自力ラインを一律に先頭へ移し、斬ったラインを下げていた。このため中団を確保した捲り型2車ラインが、理由なく位置を捨てて先行する候補として強く出ることがあった。

## 変更
- 斬ったラインがそのまま先行する選択を保持し、その戦術的不一致も記録する。
- 元中団が主導権を引き受ける選択は、先行意欲、中団で捲る利点、ライン長、上昇負担を比較した説明と一緒に保存する。
- 後方ラインの巻き返しは、瞬間的に先頭へ配置するのでなく既存の `attack()` からカマシ・早めの捲りの進行を開始する。
- 後方から一挙に先頭へ配置する直接 `press` を禁止。外進行からの成立を要求する。
- 原則として好位の捲り型は好位維持の価値を持ち、先行型なら先頭を狙う利益も評価する。2車ラインだから先行禁止、3車ラインだから必ず先行とはしない。
- 先頭を取らなかった3車ラインは、能力・位置・長く踏む傾向に応じカマシ・捲りの別候補を検討する。
- 各仮説の行動理由に先行・中団の比較要素を残す。比較係数は未校正であり確率ではない。

## 検証
`tests/line/cut-choice.test.cjs` で、3分戦における主導権据置・中団からの先行・中団維持・外からの仕掛けが探索に存在することを確認する。既存LABとLINEのテスト、iPhoneの画面テスト、発走前保存の不変性も継続。

## 留意点
本修正は大宮12Rの着順から逆算して戦術を固定するものではない。実際の事前出走表に対するモデル固有の候補順位や実戦映像の位置取り照合は別途必要。
