## 公開アーカイブの拡張候補

`snarfnet/keirin-data` の公開Git履歴の固定リビジョンから182日分（2026-05-19〜11-16）を調査した。ファイルの最終版にさかのぼって発走前時刻を付けず、公開履歴のコミット時刻が予定発走の10分以上前にある版から同一レースを一意に数えた。10分は発走基準であり、二車単市場の締切時刻の証拠ではない。

| アーカイブ上の照合 | 7車 | 9車 | 合計 |
| --- | ---: | ---: | ---: |
| 予定発走10分以上前に出走表版がある | 11,700 | 1,155 | 12,855 |
| 同一IDの結果がある | 10,446 | 1,045 | 11,491 |
| 結果掲載の全選手名と車番が出走表に一致し、二車単払戻も確認 | 10,357 | 1,038 | 11,395 |
| 発走前のライン、競技区分、選手IDと結果のBを揃えて現行V1に投入 | 0 | 0 | 0 |

このアーカイブには出走表のライン・男子区分・選手ID、結果のB欄がない。取得コードで確認したオッズは三連単。公開出走表候補には男子確認前の行も含まれる。二車単払戻、決まり手、コメントからBやラインを埋めていない。

既存の日別出走表配信は、今回参照できたGit履歴が5コミットで、11月16日より前の発走前版は残っていなかった。11月16日の未収録候補は保存時点の競走得点0.0などが残り、本人照合済みの既存近走資料でも同時点の得点は取得できなかった。公開コードの別候補には、発走前オッズの保管先が運用者のローカルディスクと説明されているものもある。元論文の学習データ一式、3年以上の現行条件の学習用アーカイブ、締切前の二車単オッズは確保できなかった。

## 再実行

`two_t.archive_coverage` は公開履歴から候補数と欠損を集計する。`two_t.supplement` はV1学習資料のIDを除き、別エンジンの事前保存カードと、指定した公開リビジョンの出走表を確認する。いずれも監査結果の出力先を指定して実行できる。原始アーカイブ、予想データ、既存テスト期間への書き込みはない。

```bash
python -m two_t.archive_coverage /path/to/snarfnet-keirin-data /tmp/2t-archive.json \
  --ref 6ea68de4d92d3a8294e1a7d168e918a8a90eb155
python -m two_t.supplement --baseline /path/to/inputs/dataset-7.json \
  --baseline /path/to/inputs/dataset-9.json \
  --public-checkout /path/to/keirin-app-data \
  --ref-day c27d313 2026-11-16 --ref-day 4588ec9 2026-11-16 --ref-day 576426b 2026-11-16 \
  --venue-page /path/to/winticket-racecard.html --out /tmp/2t-supplement.json
python -m unittest discover -s tests/two_t -v
```

数値の内訳と追加4レースの出典は [監査JSON](2T_ARCHIVE_COVERAGE.json)。
