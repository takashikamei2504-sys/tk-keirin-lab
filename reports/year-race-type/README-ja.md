# 競輪：級班×レース種別 1年検証の入力監査（2026-11-16）

## 対象と結論

- 依頼：2025-11-16〜2026-11-15の男子7・9車を、勝ち上がり戦・決勝・負け戦・初日特選等に分類。既存LAB8方式を当てはめ、級班×番組で的中率・ROIを比較する。
- 日付正規化後の年間公開CSVのレース数 **25,139R**。主要4区分の男子7・9車 **21,695R**。そのうち三連単払戻を解析できた **14,118R**。これは公式照合ではない。なお、初回の25,133R・14,106Rは、CSVの日付ずれ未補正の暫定値だったため、こちらの数値を優先する。
- 4主区分（収録R／3連単表記あり）：A級7車 **10,516／6,836**、S級7車 **4,556／2,934**、S級9車 **2,099／1,414**、チャレンジ7車 **4,524／2,934**。ほかA級9車3、チャレンジ9車2（すべて日付正規化後）。
- 利用データ：公開リポジトリ [Kenseimk/keirin-data](https://github.com/Kenseimk/keirin-data) の2025_11〜2026_11月別CSV。対象年月境界を日付で切り、重複レースIDを除いたもの。
- **この年間CSVから現行LAB8方式の年間成績は出せない**。レース名／決勝等の番組区分、開催日次、実際のライン先頭・番手・3番手、発走時刻が収録されていない。 `lineup` と称するカラムは「◎1 ○3 ...」などの予想印で、ラインではない。
- 結果を見て「初日特選」や「準決勝」をレース番号から後付け推測すること、予想印を隊列として投入すること、他条件の3か月結果を「1年検証」と表示することは禁止。

## 追加実施中の対象（年間検証の代用品ではない）

公開日別JSON [kurinaka12-afk/keirin-app-data](https://github.com/kurinaka12-afk/keirin-app-data) が残る2026-08-18〜2026-11-15に限って、正しい `round_name`、`venue_info[].meeting_day`、`entries[].line_position` と払戻を使用した探索的なレース種別再生成を実施する。

- レース分類は、結果を見ずに、準決勝・予選など「勝ち上がり戦」、決勝、初日特選、敗者戦、その他を区分する。初日特選は必ず「初日」情報とレース名の両方が揃う場合のみ判定する。
- エンジンは AUTO、物理修正版、因果展開、LAB V5、LAB LINE、ROI COVERAGE、B-UPSET A〜D、B-UPSET拡張の8方式を現行コードで過去カードに適用。
- 買い目は方式ごとに重複除去し、3連単各100円。ROIは総払戻÷総投資で、最高払戻1件・5件除外と月別ブレを別表示。
- 各級班×番組ステージで最大75RをSHA256で結果非参照抽出。これ自体も探索であり、選定後の未使用期間検証が必要。
- 「事後再生成」はその開催当時に発走前に固定保存した予想とは異なる。年月によるデータ改訂やモデル改善の混入を排除できない。
- 正確な1年比較を完成するには、**開催当時の正しいライン・レース区分・級班・競走得点・3連単払戻を揃える**必要がある。私的利用条件や利用許諾も確認し、無理な取得・他者データの再配布は避ける。

## 2026-11-16 追加：年間データの日付・レースID整合性を修正

13か月分のCSVで、16桁レースIDに「開催開始日」と「開催何日目か」が含まれていることを、外部の日別出走表と照合して確認した。

- レースIDから計算した日付とCSVの日付が直接一致したものは、**23,119R**。CSVが開催初日を実施日として表示しているものは、**3,171R**（期間外も含む）。それ以外は異常な開催日次34R、不一致27R。
- 2025-11-16〜2026-11-15に絞った正規化対象では、**2,388Rの実施日を補正**。矛盾61Rは推定で補わず集計から除外。
- この修正を入れずに「初日」「最終日」を判定すると誤分類する。
- 日付補正後は **計25,139R**、主要4級班男子7/9車 **21,695R**、解析可能な3連単結果 **14,118R**。
- ただし、開催何日目かが分かっても、正確な「特選／予選／準決／決勝／一般／選抜」やライン構成が復元されるわけではない。

監査結果：`reports/year-race-type/race-id-date-integrity.json`、`reports/year-race-type/annual-normalized-inventory.json`。

## 直近90日の833R探索的8方式比較（年間成績ではない）

結果を見ずに級班×段階ごと最大75Rを抽出した833Rを、8方式すべてに事後適用した。買い目は各100円。

| 方式 | 全体回収率 | 最高払戻5件除外 |
|---|---:|---:|
| AUTO | **112.3%** | 78.0% |
| 因果展開型 | 94.3% | 59.9% |
| 物理修正版 | 94.0% | 66.8% |
| LAB LINE | 87.2% | 53.4% |
| ROI COVERAGE | 72.9% | 47.2% |
| B-UPSET拡張 | 64.9% | 46.5% |
| B-UPSET A〜D | 62.1% | 43.6% |
| LAB V5 | 59.0% | 45.3% |

AUTOの112.3%は最高払戻5件除外で78.0%となる。過去に指定した級班だけの最適選択は採用せず、レース前に得られる追加条件での未使用時系列データによる検証が必要。
