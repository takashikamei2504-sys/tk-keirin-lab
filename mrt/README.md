# Mr.T研究 V3 / 手動Bライン

`mrt.html` が男子7・9車の自動／手動Bライン画面。ホームとLAB LINEから移動できます。既存エンジンのモデル・買い目は変更しません。

採用中V3（学習7,126件、履歴2026-11-21）を使用。重みSHA256：`2704d1ce9964a3365507595b70174dfc81959e8fc3009dbac4bdb98553454b2b`。V4研究候補には切り替えません。保存済みモデルの読み込みのみで、配信時の再学習はありません。

## 配信

```sh
pip install -r mrt/requirements.txt
python -m mrt.publish
python -m mrt.results
```

日付指定は `python -m mrt.publish --date YYYY-MM-DD`。履歴日以前と締切後の新規予測生成を拒否。公開一覧の競輪場タブで実際に掲載されたレースURLだけ取得し、HTTP 401/403/429で停止。1秒以上のリクエスト間隔、25秒タイムアウト。先生の印・記事・現在レースの結果は特徴量にしません。

一般出走表の正規URL、タイトルの日付・場・R、車番と登録番号の重複、得点・脚質、並びの全車一致、発走／締切時刻を検査。ガールズ、並び欠損、欠車等の不整合は利用不可。未確定の単騎を創作しません。

自動と既知各ライン×2方式を1万円で事前計算。先頭車B固定（標準）／指定ライン内のBウェイト再配分を選択。B条件は1着やライン独占を固定しません。全三連単候補からV3の条件付きスコアで選び、従来と同じ配分を使用します。スコアは校正済み的中確率ではありません。

`data/mrt/日付/レースID-指紋.json` は生成済み予測・完全入力・モデル／コードSHA・取得／生成／締切時刻を持つ不変スナップショット。`index.json` は毎回の再確認状態。出走者・並び・時刻変更は新入力として扱い、エラー時は古い予測を現在のものとして表示しません。予測未配信の終了レースに後付け予測を作りません。

GitHub Actionsは毎時04分・34分（遅延あり）に配信・直近7日照合。定期処理では推論／検査のみ。ソース変更時は加えてモバイルブラウザテストを実行します。公開リポジトリの既存Actions/Pagesを使用し、課金サービスは追加しません。

## 端末保存と結果

ブラウザは条件ごとの計算済み結果を切替表示。指定条件を解説・JSONに含めます。条件／レース変更時は以前の結果を消し、明示的な生成操作後にだけ表示・保存します。自動／手動ライン／B取得者ルールごとに最初の締切前表示を固定保存。入力指紋とエンジン指紋も保存キーに含め、再描画で上書きしません。

最新の入力確認から75分を超えた場合と締切後は参考表示のみ。端末時計・Safariの保存領域に依存するため、サーバーによる手動選択の発走前証明ではありません。サーバーに保存される各条件の計算候補と、利用者が実際に端末で選んだ予測は区別します。

結果は正規URL、発走時刻、車番別の登録番号と三連単払戻を照合。同着は払戻組合せで計算。欠車・失格・棄権など不規則な結果や未確認資料は対象外／結果待ちとして扱い、不的中に置き換えません。端末で自動・各手動条件を分けて仮想回収率を集計。手動指定の優位性は未検証です。

## 検証

```sh
python -m unittest discover -s tests/mrt -p 'test_*.py'
node tests/mrt/core.test.cjs
node tests/mrt/browser.cjs
```

Python43件、Nodeの選択・金額・不正指定・締切・鮮度・非上書き・別条件保存・結果本人照合を検証。ブラウザテストは実配信スナップショットを固定時計で使用し、7/9車・320/390px・条件変更・締切後保存拒否・JSON保存を検証します。過去回収率を機能追加の成績や手動指定の成績に流用しません。
