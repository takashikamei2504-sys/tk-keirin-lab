# TK KEIRIN LAB v0.2（iPhone向けオフライン試作）

## 新機能

- 7車・9車の出走表JSONを読み込む
- 予想（買い目）をブラウザ内の`localStorage`に保存
- 3連単の確定着順と100円当たり払戻金を手入力し、机上の的中率・回収率を計算
- 日時（JST）で「発走前保存」と「発走後の再現テスト」を区分。後者は成績に集計しない
- 予想記録のJSONバックアップ書き出し・再読み込み

## iPhoneで使うには

このHTMLはオフラインで動く試作です。ただしiOSのファイルアプリでHTMLを開くとブラウザ機能・ローカル保存が制限される場合があります。PCのChrome等で開くか、独立したGitHubリポジトリからGitHub Pagesに公開してSafariで使用してください。GitHub Pagesは一般公開になるため、機微なデータや非公開の個人情報は配置しないでください。公開設定はユーザーの意思決定後に行います。

1. `index.html` をブラウザで開きます。デモは2026/10/31の防府12Rです。
2. 「予想保存・結果検証」で「現在の予想を保存」を選ぶとサンプルの再現テストとして登録され、実戦集計には含まれません。
3. 別レースの出走表を入力して発走前に保存すると、実戦検証の対象です。
4. レース確定後に、3連単着順（例 `2-8-7`）と100円あたり払戻金を入力して登録します。
5. 時々「記録をJSONで書き出す」でバックアップします。端末のストレージ削除・シークレットモードでは保存記録が失われることがあります。

## 重要な注意

- **学習済みAIではありません**。出走表ベースの暫定的なルールベースの候補抽出です。
- オッズは未入力。期待値や配当帯を加味した選定はしていません。
- 単純な架空購入額は、全候補に100円ずつ均等に投じたと仮定して算出（実際の購入ではありません）。
- 発走前保存の判定は端末時刻によります。独立したタイムスタンプ証明はありません。よって機械的なバックテストには別途データソースが必要です。
- 参照元と自動収集の利用許諾を確認するまでは、データの大量自動取得は行いません。
- 静的ページは端末間同期がありません。ZIPも本番の運用環境ではありません。
- データを外部送信しません。予想と結果の登録はローカルのみです。

## 予想用出走表JSONの形式

`race_sample.json` を参照してください。ラインの先頭は先頭選手、後続は番手・３番手です。JSONと結果の整合性はブラウザ側で検証します。


## GitHubへのアップロード（iPhone・初回）

1. このZIPをiPhoneの「ファイル」アプリに保存してタップし、展開する。
2. Safariで `https://github.com/takashikamei2504-sys/tk-keirin-lab` を開いてログイン。
3. 空リポジトリの **uploading an existing file** を選ぶ。表示されなければ `Add file` → `Upload files` を選ぶ。
4. 展開した3ファイル `index.html`, `README.md`, `race_sample.json` を選んでアップロードし、**Commit changes** を押す。
5. Settings → Pages → Build and deployment → Source を `Deploy from a branch` に変更し、Branch `main` / `/(root)` を選び、Save。

公開後のURL候補: `https://takashikamei2504-sys.github.io/tk-keirin-lab/`（ページが公開されたことを確認するまでは未開通です）。

このリポジトリはPublicです。APIトークン、非公開個人情報、購入記録などをコミットしないでください。予想履歴は端末内のみ保存され、定期的なJSONバックアップが必要です。
