# TK KEIRIN LAB v1.4

[独立展開推理を開く](https://takashikamei2504-sys.github.io/tk-keirin-lab/v14.html) · [従来v1.2](https://takashikamei2504-sys.github.io/tk-keirin-lab/v12.html) · [添付の元v1.3](v13.html)

## 今回の実装

v1.3の画面を基に、別ファイルの独立エンジン `js/race-brain.js` を接続。従来のAI印・買い目・手入力の人物仮説・特定選手の固定シードから独立して生成する。

- 公開記事本文をPython標準ライブラリだけで自動収集。東スポ競輪・KEIRINスポニチ・netkeirinの公開一覧から記事を発見し、本文・公開日時を検査。記事見出しや検索スニペットは特性の根拠にしない。
- 当日・翌日の公開出走表から選手名簿を自動構成。本文中の明示的な単独主語から、前受け・突っ張り・引き・カマシ・追走・番手はまり・再自力・差し・大外の観察を抽出。複数選手の混在、否定・仮定、日付不明、取得不可は採用せず状態を記録。
- 選手特性は記事観察と脚質・得点等の暫定値を統合。単一記事を恒常的な性格と断定しない。古い情報は減衰し、同じ記事の重複で強化しない。
- 周回→打鐘→最終ホーム→最終バック→直線の隊列と消耗を保持。離れで空いた番手は近くの別線が利用し、再自力は追走喪失→後退→外への仕掛けとして生成。
- 他の条件を揃えた対の判断分岐からキーマン3人を抽出。3連単は重複なし20点。上位16点に番手はまり・再自力・大外等の別筋を追加する。
- 記事根拠・情報不足・出典・公開／取得日時を画面に表示。レース切替で再計算。20点コピー・JSON保存に対応。

## 利用方法

`v14.html` をSafariで開き、開催日・場・Rを選び出走表を取得する。記事の入力・採用操作は不要。記事データはページ読込時に自動取得する。出走表提供元に対象日や並びがない場合は取得できないため、画面で理由を表示する。

v1.2は変更せず `v12.html` に維持。添付v1.3も `v13.html` にそのまま保持。旧トップページは `v02.html`。新トップページはv1.4へ案内する。

## 自動更新・費用

`.github/workflows/collect-intelligence.yml` は日本時間06:20・12:20・18:20に最大36記事を収集（GitHubの混雑で遅延する場合あり）。初回pushと手動実行にも対応。公開リポジトリの標準GitHub ActionsとPagesを使い、課金API・新規有料サービス・APIキーを使わない。リポジトリ／組織側でActionsを無効化している場合は実行されない。

収集はrobots.txtを確認し、サイトごとの間隔と記事数・時間を制限。本文全体は保存せず、短い根拠と出典だけ保存する。ログイン・有料記事の回避はしない。サイトの構造変更等で失敗した場合は既存の根拠を保持し、収集状態を更新する。

## 検証・制限

```sh
node tests/brain.test.js
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/collect_intel.py --max-articles 36
python3 scripts/build_page.py
```

この版は**ルールによる因果仮説生成器**。学習済み言語モデルによる自由読解や校正済み的中確率ではない。選手特性・展開スコア・20点の選び方には未検証の仮定がある。精度・回収率の検証は後続課題。未提供B/S・着数は実測ゼロとみなさず欠損扱い。記事不足時は暫定値を明示して継続する。

過去レースでは記事公開日時と初回取得日時がどちらも発走前の根拠のみ適用し、後日収集による再現を発走前予想に見せない。記事コーパスはこれから蓄積するため、初期段階では根拠のない選手が多い。従来モデルの保存・検証機能は従来の予想を対象とし、新しい独立20点は専用JSON／コピーから保存する。
